# Contributing / Katkı

English: Open an issue describing the problem without tokens, real participant IDs or private replies. Use Node.js 24 and a separate clean checkout with no real `.env`. Run the README checks before proposing a pull request. Add behavior tests for permission, consent or data-lifecycle changes. Keep both README languages current and preserve minimal permissions, bounded RAM, explicit confirmation and no unsolicited communication. Never commit secrets. Do not run a second process on an existing bot token. A disposable test Discord application/server can be used for operator live checks; do not capture sensitive content.

Türkçe: Sorunu token, gerçek katılımcı kimliği veya özel yanıt eklemeden issue ile açıklayın. Node.js 24 ve gerçek `.env` içermeyen ayrı temiz checkout kullanın. PR öncesi README kontrollerini çalıştırın. İzin, rıza ve veri ömrü değişikliklerine davranış testi ekleyin. İki dilde README'yi güncel tutun; en az yetki, sınırlı RAM, açık onay ve istenmeyen iletişim göndermeme sınırlarını koruyun. Sırları commit etmeyin. Mevcut bot tokenıyla ikinci süreç başlatmayın. Canlı kontrol için ayrı test uygulaması/sunucusu kullanabilirsiniz; hassas içeriği kaydetmeyin.
