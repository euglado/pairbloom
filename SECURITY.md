# Security / Güvenlik

English: Do not post live tokens, `.env`, real rosters or private replies in issues. Reset an exposed token immediately through Discord Developer Portal, stop the process and reconfigure privately. For a vulnerability use this repository's Security tab → Report a vulnerability if private reporting is available. If not, open only a minimal issue asking for a private reporting channel, without exploit details or user data. Do not test against other people's servers. Automated scans are heuristic, and no guaranteed response time is offered. Operators remain responsible for host access, backups, dependency updates and Discord policies.

Türkçe: Canlı token, `.env`, gerçek katılım listesi veya özel yanıtları issue olarak paylaşmayın. Sızan tokenı hemen Discord Developer Portal'dan sıfırlayın, süreci durdurun ve gizlice yeniden yapılandırın. Açık için depodaki Security → Report a vulnerability özel bildirim özelliği varsa kullanın. Yoksa yalnızca özel bildirim kanalı isteyen, istismar ayrıntısı ve kullanıcı verisi içermeyen küçük bir issue açın. Başkalarının sunucularında test yapmayın. Otomatik taramalar sezgiseldir; yanıt süresi garantisi yoktur. Host erişimi, yedekler, bağımlılık güncellemeleri ve Discord kuralları işletmecinin sorumluluğudur.
